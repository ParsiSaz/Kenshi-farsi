# Changelog & Version History

All notable changes to the **Kenshi Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Standardized project documentation and README to comply with **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Documented engine hurdles: OGRE font atlas injection, reverse character order, and non-connected glyphs.
- Linked direct installation guides and troubleshooting to the central [ParsiSaz Documentation Portal](https://parsisaz.github.io/parsisaz/).

---

## [v1.1.0] - 2024-05-10

### Added
- Main dialogue lines and GUI strings translation in `locale/fa_IR/`.
- Pre-compiled `main.mo` for faster in-game string lookup.

---

## [v1.0.0] - 2023-01-15

### Initial Release
- Initial Persian locale extraction and experimental font support for Kenshi.
